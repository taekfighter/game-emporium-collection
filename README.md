## 📦 About this project

</div>

Google Drive Hub was a Firebase-hosted web application with a browser-based frontend and game-related files. This is a historical description only; features and external services may no longer work as expected.

## 🗂️ Repository contents

- **Web application:** HTML, JavaScript, and related frontend files.
- **Game-related files:** [`UGS-Files`](https://github.com/taekfighter/google-drive-game-repository/tree/main/UGS-Files) in the separate game repository.
- **Firebase Hosting configuration:** [`firebase.json`](./firebase.json).
- **Automated deployment workflows:** [`.github/workflows/`](./.github/workflows/).

The presence of deployment configuration does **not** mean deployment is safe or supported.
